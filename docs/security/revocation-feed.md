# Required revocation source contract

Production `RevocationReconciler` requires a `RevocationSourceVerifier` enrolled with a cell, finalized identity issuer and bounded Ed25519 public-key set. The external identity service owns signing keys. A valid signature authenticates that service's coverage assertion; it does not establish that an arbitrary page is complete.

A batch declares all seven fields: `fromOffset`, `highWater` (page cursor), `events`, `checkedAt`, `sourceProof`, `retiredKeys`, and `currentSourceHighWater` (the source's current authoritative high-water). There are at most 16 combined events/key retirements. The source attests complete coverage of the range `(fromOffset, highWater]` for the selected cell, including every applicable session/user revocation and issuer-wide key retirement. Skipped offsets must be irrelevant to that cell, as established by the finalized source partition/directory contract. A complete current range has `highWater == currentSourceHighWater`; callers must never manufacture that equality from a historical page cursor.

`sourceProof` is `<enrolled-key-id>.<unpadded-base64url-Ed25519-signature>`. The signature covers the binary length-prefixed domain `signaling-revocation-source-v1`, the destination cell and issuer, both cursors and current high-water, source observation time, ordered events and retirements. `RevocationSourceVerifier.signingBytes` defines the exact representation. Different cells/issuers, missing pins, changed completeness/timestamp/event data or unknown signatures are rejected. Tokens cannot choose source endpoints or keys.

The native primary independently checks source age (at most five seconds), current storage roots, exact cursor continuation and replay. Partial pages atomically advance security epochs, invalidate affected session routes and advance the durable cursor, while setting source freshness to unknown. Existing freshness is invalidated immediately when catch-up is known to be incomplete. Only a newly authenticated complete current range restores freshness; historical replay cannot do so. Native progress exports the older of local application time and source time.

Source transport must be private authenticated TLS, use one bounded request budget and bounded payloads/pages, and start from the durable native cursor after restart. Its authenticated partition and high-water behavior must be exercised during lag, key retirement, directory migration and source outages. Gateway cached invalidation and periodic source polling must be wired before runtime readiness; these consumer classes alone do not provide the external service or qualify propagation latency. Release remains NOT_QUALIFIED until same-candidate production evidence exists.
